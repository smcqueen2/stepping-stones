# Site icon

The original, editable artwork is [favicon.svg](../../public/favicon.svg): three large cream stepping stones crossing a muted blue river diagonally. The owner preferred this simpler mark to the first castle-and-stones design. Cream (`#f8f5ed`) and river blue (`#4d8190`, with a darker `#386574` current) match the site's palette. The larger, separated stones stay readable at small browser-tab sizes. This is a hand-authored vector mark, with no fonts, external images or image-generation service.

`index.html` links to the SVG, a 32px PNG fallback, a multi-resolution ICO (16/32/48px), and a 180px Apple touch icon. Paths use Vite's `%BASE_URL%` so GitHub Pages' repository subdirectory is respected. The `v=2` query refreshes cached copies of the first design; increment it for future artwork updates. The Apple export has an opaque river-blue background for platform masking. No web-app manifest or service worker is needed for this change.

Raster exports were rendered directly from the SVG with `@resvg/resvg-js` 2.6.2 in a separate local tooling directory, and the ICO was packed from the rendered sizes using Pillow. Neither tool is a frontend dependency or part of the normal build. To regenerate, render the SVG at 16, 32, 48 and 180 pixels, use the river-blue background for the Apple icon, and pack the three smaller sizes into `favicon.ico`. Preserve the SVG as the source of truth.
