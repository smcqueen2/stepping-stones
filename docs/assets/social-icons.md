# About-page social icons

Added 6 November 2026 at the owner's request. GitHub links to the verified repository remote, https://github.com/smcqueen2/stepping-stones; LinkedIn uses the exact supplied profile URL, https://www.linkedin.com/in/stephenmcqueen/.

The two paths are inline SVGs from [Bootstrap Icons](https://icons.getbootstrap.com/), copied from its official repository:

- [github.svg](https://github.com/twbs/icons/blob/main/icons/github.svg)
- [linkedin.svg](https://github.com/twbs/icons/blob/main/icons/linkedin.svg)

No icon font, JavaScript package, external image request or generated bitmap. Display size is 20px with visible text, 44px link targets and existing keyboard-focus styling. The SVGs are decorative/hidden from assistive technology; accessible link names identify the destination and announce opening a new tab. Links use `target="_blank"` and `rel="noopener noreferrer"`.

The upstream MIT copyright/permission notice is distributed at `public/licenses/bootstrap-icons.txt`, copied into the built site at `licenses/bootstrap-icons.txt`.
